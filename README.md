# ChoochBotTgDemo

Telegram-бот для групповых чатов (`group`/`supergroup`): поддерживает беседу через DeepSeek AI с памятью диалога, скачивает видео по ссылкам прямо в чат, умеет тегировать участников, поздравлять с днём рождения и собирать статистику. Для чтения всех сообщений группы в BotFather у бота должен быть выключен Privacy Mode.

## Возможности

- **ИИ-беседа с памятью.** Бот сам решает, когда отвечать; помнит последние сообщения (SQLite), длинные диалоги автоматически сжимаются в саммари, личность чата настраивается командой.
- **Скачивание видео** (mp4): YouTube, TikTok, PornHub.
- **Команды** для владельцев и участников: личность, память, раскладка/азбука Морзе, статистика, теги.
- **Теги участников**: `/all` и именованные группы `/tag` — упоминания собираются из `@username` и сущности `text_mention`.
- **Дни рождения**: бот спрашивает дату при входе и поздравляет именинника в 00:00.
- **Чтение ссылок**: при включённой функции `links` содержание страницы попадает в контекст беседы.
- **Функции включаются гибко**: глобально — файлом `filters/handlers.txt`, в конкретном чате — командой `/feature`.

## Требования

- Python 3.14, Windows.
- Зависимости из `requirements.txt`: aiogram 3, aiohttp, aiosqlite, pydantic-settings, openai (DeepSeek), yt-dlp, playwright, curl_cffi, ffmpeg.
- В корень проекта кладётся `ffmpeg.exe` (в git не хранится): нужен для YouTube (сборка mp4) и PornHub (перекодирование MPEG-TS → MP4).

## Установка и запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
```

В корне создаётся файл `.env`:

```env
BOT_TOKEN=<токен бота от @BotFather>
AI_API_TOKEN=<ключ DeepSeek API>
```

Запуск:

```bash
python main.py
```

При старте создаётся схема SQLite (`AI_module/bot_talker_memory.db`), поднимается фоновый браузер Playwright; при остановке он закрывается. Бот работает в Long Polling и обрабатывает только групповые чаты.

## Функции (тогглы)

Список функций, описание и правило включения:

| Функция | Что делает |
|---|---|
| `youtube` | скачивание видео с YouTube |
| `tiktok` | скачивание видео с TikTok |
| `pornhub` | скачивание видео с PornHub |
| `bug` | реакция на слово «баг» |
| `AI_chating_responce` | генерация ответов в беседе |
| `AI_chating_memory` | запоминание истории беседы |
| `links` | чтение содержимого ссылок (новости, статьи, посты) |
| `transliterate_auto` | автоисправление раскладки |
| `stats` | статистика бота |
| `group_tag_all` | тег `/all` — всех участников чата |
| `group_tag` | группы участников `/tag` |
| `birthdays` | поздравления с днём рождения |

**Правила включения.** В `filters/handlers.txt` строка без `#` — функция разрешена глобально (по умолчанию включена во всех чатах); закомментированная — запрещена глобально и не может быть включена ни в одном чате. Внутри чата функцию можно выключить/включить командой `/feature <имя> on|off`; глобальный запрет всегда приоритетнее выбора чата. Правки `filters/handlers.txt` применяются при перезапуске бота.

## Скачивание видео

Платформа определяется по подстрокам из `filters/youtube.txt`, `filters/tiktok.txt`, `filters/pornhub.txt` (регистр не важен, поддерживаются ссылки-гипертекст). Скачанный файл отправляется в чат и удаляется с диска.

- **YouTube** — yt-dlp: клиенты `tv`/`visionos`/`web_embedded`, ffmpeg-сборка mp4 (h264+aac).
- **TikTok** — Playwright (персистентный headless-Chromium): CDN-ссылка извлекается из `__UNIVERSAL_DATA_FOR_REHYDRATION__`.
- **PornHub** — yt-dlp: форматы перебираются от лучшего к худшему, варианты больше 48 МБ отсекаются через `max_filesize`.

Ссылки, которые забирает скачивание видео, не читаются модулем чтения ссылок (`links`) — зоны разграничены общей проверкой `filters.is_video_url`.

## Теги участников (/all и /tag)

Бот знает участников, оставивших след: писавших в чат, вошедших при работающем боте или подтверждённых админской сверкой при старте. `/all` тегает всех таких участников.

- `/tag create <имя> [@ники...]` — создать группу участников.
- `/tag <имя>` — тегнуть участников группы.
- `/tag <имя> add|remove [@ники...]` — изменить состав (`add` без списка — все участники чата).
- `/tag list` — показать все теги чата, `/tag clear` — удалить их.

Участник без `@username` упоминается сущностью `text_mention` по id; участник, которого бот ещё не видел, добавляется по нику и тегается текстом «@ник». Имена `create`, `list`, `clear` зарезервированы под команды.

## Дни рождения

Bot API не отдаёт дату рождения участника в групповых апдейтах, поэтому при входе нового участника (или при добавлении бота в чат) бот спрашивает её прямо в чате; свою дату может указать любой участник сообщением вида `ДД.ММ[.ГГГГ]`. Поздравление публикуется в 00:00 по локальному времени машины (или при первом запуске, если бот не работал). Текст генерирует AI в стиле личности чата; расход токенов учитывается в статистике. При выходе участника его дата удаляется.

## Чтение ссылок (links)

При включённой функции `links` бот скачивает присланную ссылку и добавляет содержание страницы (заголовок, текст статьи/поста) к сообщению в истории — болталка учитывает суть ссылки при решении об ответе. Читаются только HTML-страницы; видео-ссылки и недоступные сайты пропускаются без последствий. Тоггл независим от памяти, но содержимое попадает в историю, поэтому чтение работает вместе с включённой `AI_chating_memory`.

## Статистика

Собираются: обработанные сообщения, команды, решения «отвечать/молчать» с причинами, попытки скачивания видео, расход токенов DeepSeek по функциям. Тариф для расчёта стоимости — в `stats/prices.txt`.

Разделы: `summary`, `top`, `video`, `tokens`; периоды: `all`, `today`, `yesterday`, `week`, `month`. Раздел `global` (например, `/stats global week`) считает по всем чатам сразу.

## Ограничения и особенности

- Работает только в группах (`group`/`supergroup`) при выключенном Privacy Mode.
- Лимит Telegram на размер видео — 48 МБ.
- Скорость скачивания с PornHub зависит от CDN-сервера; TikTok/WAF может отклонять запросы — иногда нужен повтор.
- События входа/выхода в супергруппе бот получает только будучи администратором.
