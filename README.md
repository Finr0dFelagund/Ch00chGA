# ChoochBotTgDemo

Telegram-бот для групповых чатов (`group`/`supergroup`): ведёт диалоги через DeepSeek AI, помнит историю разговора и скачивает видео по ссылкам прямо в чат. Скачивание работает без cookies.

## Возможности

- ИИ-общение с памятью: история в SQLite (до 100 последних сообщений), бот сам решает, когда отвечать; длинные диалоги автоматически сжимаются в саммари.
- Личность чата настраивается через `/set_personality`, просматривается через `/get_personality`.
- Скачивание видео по ссылкам (mp4):
  - YouTube — yt-dlp + ffmpeg;
  - TikTok — Playwright (персистентный headless-Chromium);
  - PornHub — yt-dlp с impersonation (curl_cffi).
- Реакция на слово «баг» в чате.
- Исправление раскладки: команда `/transliterate` (ru/en, азбука Морзе) и автоисправление текста в неправильной раскладке через LLM-гейт.
- Функции включаются/выключаются правкой `filters/handlers.txt`; индивидуально для чата — командами `/features` (статус) и `/feature <имя> on|off`. Закомментированная в файле функция запрещена глобально и не включается ни в одном чате.
- Статистика: `/stats` — обработанные сообщения, активные пользователи, команды, скачивания видео, токены и стоимость DeepSeek по функциям, с разбивкой по периодам.
- Теги участников: `/all` — тегание всех, кто оставил след в чате; `/tag` — именованные группы участников (создание, изменение состава, тегание). Участники без @username упоминаются по id через сущность `text_mention`. Добавлять в тег можно и тех, кого бот ещё не видел, — по их @нику: они тегаются текстом «@ник».

## Стек

Python 3.14, aiogram 3.x (Long Polling), DeepSeek API (`openai`, модель `deepseek-chat`), SQLite (`aiosqlite`), yt-dlp, ffmpeg, Playwright, curl_cffi, pydantic-settings.

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
```

Браузер Playwright нужен для скачивания TikTok.

Для слияния и перекодирования видео в корень проекта нужно положить `ffmpeg.exe` — в git бинарник не хранится (см. «Скачивание видео»).

## Конфигурация

В корне создаётся файл `.env`:

```env
BOT_TOKEN=<токен бота от @BotFather>
AI_API_TOKEN=<ключ DeepSeek API>
```

## Запуск

```bash
python main.py
```

При старте создаётся схема SQLite (`AI_module/bot_talker_memory.db`) и поднимается браузер Playwright; при остановке он закрывается. Для чтения всех сообщений группы у бота в BotFather должен быть выключен Privacy Mode.

## Команды

| Команда | Описание |
|---|---|
| `/help` | Справка |
| `/set_personality <текст>` | Задать личность чата |
| `/get_personality` | Показать текущую личность |
| `/clear` | Стереть всю память чата |
| `/clear N` | Стереть последние N сообщений |
| `/transliterate [from] [to] [text]` | Исправить раскладку (ru/en) или азбука Морзе: `/transliterate en ru Ghbdtn` |

| `/stats [раздел] [период]` | Статистика: `summary`/`top`/`video`/`tokens`/`global`; период `all`/`today`/`yesterday`/`week`/`month` |
| `/all` | Тегнуть всех известных участников чата |

| `/tag <имя> add\|remove [@ники...]` | Изменить состав группы; `add` без списка — все участники чата, `remove` без списка — удалить тег |
| `/tag list` | Показать все теги чата |
| `/tag clear` | Удалить все теги чата |

## Скачивание видео

По ссылке в чате платформа определяется по подстрокам из `filters/*.txt` (регистр не важен, поддерживаются ссылки-гипертекст). Скачанный файл отправляется в чат и удаляется с диска.

- YouTube — yt-dlp (клиенты tv/visionos/web_embedded + JS-рантайм node), ffmpeg-merge в mp4 (h264+aac).
- TikTok — Playwright: CDN-ссылка извлекается из `__UNIVERSAL_DATA_FOR_REHYDRATION__`.
- PornHub — форматы перебираются от лучшего к худшему, не влезающие в лимит отсекаются через `max_filesize`.

**Требуется `ffmpeg.exe` в корне проекта** (не хранится в git): для YouTube — слияние видео и аудио в mp4, для PornHub — перекодирование MPEG-TS → MP4.

## Тогглы функций

В `filters/handlers.txt` строка без `#` — функция разрешена (по умолчанию включена во всех чатах), с `#` — запрещена глобально (не включается ни в одном чате). Внутри конкретного чата функцию можно выключить/включить командой `/feature <имя> on|off`; запрет из файла всегда приоритетнее выбора чата.

```text
youtube
tiktok
pornhub
bug
AI_chating_responce
AI_chating_memory
links
transliterate_auto
stats
group_tag_all
group_tag
birthdays
```

## Ограничения

- Только группы (`group`/`supergroup`); требуется выключенный Privacy Mode.

**Теги участников (`/all`, `/tag`):**
- В Bot API нет методов «список всех участников» и «@ник → user_id». Бот знает только тех, кто оставил след: писал в чат, вошёл при боте (событие входа) или подтверждён админской сверкой. Список `/all` строится именно из этого реестра.
- Участника, которого бот ещё не видел, можно добавить в тег по `@нику` — он хранится по нику (без привязки к user_id) и тегается текстом «@ник». Уведомление придёт, только если человек действительно состоит в чате на момент тега.
- События входа/выхода в супергруппе бот получает, только будучи администратором; `getChatMember` для произвольных участников тоже гарантированно работает при админке. Без админки чистка уехавших происходит в обычных группах (сервисные сообщения) и не происходит для «молчаливых» участников супергруппы.
- Участника без `@username` нельзя упомянуть текстом — при теге он упоминается по id сущностью `text_mention` (уведомление приходит).
- В списках (`/tag list`) участники показываются именами без `@`-упоминаний; `@ники` появляются только в тегающих сообщениях.
- Имена тегов `create`, `list`, `clear` зарезервированы под команды и как имена тегов не допускаются.

**Поздравления с днём рождения:**
- Bot API не отдаёт дату рождения участника в групповых апдейтах (`getChatMember`/`User` её не содержат; поле `birthdate` есть только у приватного чата в `getChat`) — при входе нового участника бот запрашивает дату прямо в чате.
- При добавлении бота в новый чат он публикует приглашение; свою дату может указать любой участник сообщением вида `ДД.ММ[.ГГГГ]` — она запоминается.
- Поздравление публикуется в 00:00 по локальному времени машины, где запущен бот; если бот не работал — сразу при первом запуске в день рождения.
- Текст поздравления генерирует AI (DeepSeek) в стиле личности чата и с учётом summary бесед; расход токенов учитывается в статистике.
- При выходе участника дата удаляется — после повторного входа бот спросит её снова.

**Чтение ссылок (`links`):**
- При включённой функции `links` бот скачивает присланную ссылку и добавляет содержание страницы (заголовок и текст статьи/поста) к сообщению в истории — болталка учитывает суть ссылки при решении об ответе и генерации.
- Читаются только HTML-страницы; ссылки, которые забирает скачивание видео (YouTube/TikTok/PornHub — общие списки `filters/*.txt`), link_reader не читает; файлы и недоступные сайты пропускаются без последствий.
- Тоггл независим от памяти и ответов: `/feature links off` отключает чтение. Содержание попадает в историю, поэтому чтение работает вместе с включённой памятью (`AI_chating_memory`).

- Лимит Telegram на размер видео — 48 МБ.
- Скорость скачивания с PornHub зависит от CDN сервера.
- TikTok/WAF может отклонять запросы — иногда нужен повтор.
- `requirements.txt` сохранён в UTF-16.
- Python 3.14 (release candidate) — возможна несовместимость пакетов.
